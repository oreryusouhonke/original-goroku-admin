# 名入れ工房 — 商店風商品カタログ

楽天の商品写真から商品を選び、商品のIllustratorテンプレートで名入れデータを作成するWindowsアプリです。指定された23テンプレートを30商品へ対応づけています。

## 使い方

1. 語録管理画面の「名入れ工房の商品を選ぶ」を開く。
2. 商品を探し、サイズ・版を選んで「この商品を作る」を押す。
3. Chromeの外部アプリ確認が出たら「開く」を選ぶ。
4. 名入れ工房で中央1～2文字、上段10文字、下段7文字、保存名を入力する。
5. 「見本を作成」で確認し、「AI・PDF・PNGを出力」で保存する。

名入れ工房を直接起動した場合も、アプリ内カタログから選べます。複数のサイズ・版がある商品は明示的に選択してください。ハッピは背面と両襟に対応し、襟文字は20文字以内、空欄なら下段の店名を使います。

## 寸法

幅の変更欄を空欄にすれば、選択した元テンプレートの寸法を使用します。全商品を同じ幅へ縮小しません。新トートのS/M/L、ライトナイロンマルシェのS/Mなどは別の配置を選択します。衣類の縮尺は共通テンプレートに記載された0.63/0.8/1/1.1/1.3を選びます。

カタログのmm表示は柄の配置枠であり、商品の外寸や印刷アートボードの寸法ではありません。アートボードは元AIの寸法を保持し、自動トリミングしません。元の識別番号がアートボード外にある場合はAI内へ残しますが、PNG・PDFは元アートボードの範囲で出力します。幅を手動指定すると、識別番号・前後面などを含む出力全体の幅を合わせます。

## 出力

編集用AIは文字を保持し、PDFはアウトライン化します。タオル・バスタオル・ブランケットは、元AIにある背景色のオブジェクトをAI・PDFへ含め、背景付きPNG・確認PNG・入力JSONを保存します。その他の商品は透過PNGです。背景色の近似値や新しい色は作りません。元のDTF商品番号があれば保持し、それ以外は商品識別コードを出力します。同名出力は上書きしません。

## セットアップ

Windows、Python 3.10以上（Tkinter）、IllustratorのCOM連携と、使用許諾済みのHakusyuKointaiBold/HGPEdomojiKanteiryuフォントが必要です。

```powershell
python -m pip install -r requirements.txt
.\商品テンプレート設定.ps1
.\ブラウザー起動設定.ps1
python app.py
```

商品テンプレート設定は、既定でデスクトップの「帆前掛け商店風」から原本をコピーし、SHA256でカタログとの一致を確認します。別フォルダーの場合は `-SourceFolder` を指定してください。元ファイルを変更せず、異なる既存テンプレートの上書きもしません。

この公開リポジトリに原本AI・フォント・注文データは含めません。画像は `public/naire-catalog` に格納し、ローカルの `catalog-images` キャッシュがある場合はそれを使います。アプリを移動したらブラウザー起動設定を再実行してください。

## 検証

```powershell
python -m py_compile app.py catalog.py
python app.py --smoke-test
```

GUI・入力検証のほか、実テンプレートを使って中央1/2文字のIllustrator出力を検証します。受注自動取り込みとプリンター送信は未対応です。

背景色は元Illustratorデータから選択します。バスタオル・ブランケットは色の版を選択、ハンドタオルは6色から背景を選択してください。全商品の出力アートボードは元AIのサイズを保持します。柄が収まらない場合は拡張せず作成を停止します。

前面（胸）・背面がある衣類は、元AIの両方の柄を使用します。背面は保存名-back、前面は保存名-frontの別AI・PDF・PNGに出力し、各ファイルのアートボードは元AIと同寸です。確認画像ではBACK/FRONTを並べます。確認PNGは最大900px、印刷PNGの解像度は変更しません。胸は中央の文字、背面は中央・上段・下段を元の配置へ差し替え、商品ごとの胸寸法と選択縮尺を保ちます。
